**0.19.0 预发布**（含未单独发版的 0.18.0，配套服务端 v0.19.0-rc.1，先升服务端）。
协议 v6 不变。

## 0.18.0（已验收）

- 邀请制多用户：每用户独立 Vault 全隔离、`/join/<秘钥>` 注册页、管理员用户管理
- API Token 重置：Token 落库哈希、E2EE 重置凭证做服务端门禁、设备填新 Token 一键恢复
- 认证错误码 `UNAUTHORIZED` / `TOKEN_REVOKED` / `RESET_AUTH_MISMATCH`

## 0.19.0

- 单用户多仓库：一个 Token 名下多个互相隔离的仓库（`X-Vault-ID` 选择、成员关系裁决、非成员 404、设备凭据忽略头）
- 接入向导先选仓库（始终显示，可新建）；切换仓库 = 重新走向导（作废本设备账本、保留本地笔记）
- **新仓库强制 E2EE**：空远端初始化只有「设置 E2EE 密码并初始化」，首次上传即密文
- 设置页显示当前仓库（名字/远端文件数）并可就地重命名（`PATCH /api/v1/vaults/{id}`，只改显示名）
- 一个 E2EE 密码可用于多仓库（每仓库独立盐与密钥文档）；重置门禁升级为名下任一仓库凭证均可
- 网页端仓库切换器与解锁页多仓库提示（标明解锁对象、就地切换）

## 体验优化

- 向导全流程一遍过：解锁 E2EE 弹窗叠加在向导上，不再从选仓库步重来
- 切换/新建/重命名需要账户 Token 时在弹窗内直接补填，无需绕去设置页
- 设置页就地刷新（解锁/启用 E2EE、重命名后立即反映）
- 手动「立即同步」成败都有结果消息（下载/上传数、冲突数、失败原因）；自动同步保持安静
