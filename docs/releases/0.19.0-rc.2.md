**0.19.0 第二个预发布**：修复 iOS 真机首轮实测的软键盘卡死。
配套服务端 v0.19.0-rc.1（服务端无改动）。协议 v6 不变。

## 修复（移动端软键盘，iOS 实测）

- 弹窗内输入框**回车即提交**并收起键盘：iOS 密码键盘没有收起键、还会盖住
  底部按钮——回车是唯一出口。覆盖向导 Token 补填行 / 新建仓库名、
  重命名弹窗、E2EE 设密码弹窗（首密码框回车跳确认框，确认框回车提交）
- 移动端不再自动聚焦 Token 输入框（此前错误提示一出现就弹出无法收起的
  密码键盘盖住整个界面）；桌面保留自动聚焦
- 键盘回车键显示「前往」（enterkeyhint）

其余与 0.19.0-rc.1 相同。
