**0.19.0 第四个预发布**：修复 iOS 密码管理器填充导致的第二记连坐。
配套服务端 v0.19.0-rc.3。协议 v6 不变。

## 修复（iOS 真机实测）

- **账户 Token 补填改为独立弹窗**：密码框绝不与任何文本框同处一个界面。
  此前 Token 框在弹窗内出现后，「文本框 + 密码框」组合让 WebKit 按登录
  表单配对——密码管理器自动填充会把条目的「用户名」塞进重命名的名字框，
  且名字框自此被禁第三方输入法。独立弹窗后：填充只填 Token、名字框永远
  是普通文本框、密码管理器工作流保持可用。
- 流程更顺：被拒 → 弹 Token 窗 → 填充/粘贴 → 确定 → **自动重试**
  原操作（重命名 / 向导继续）。

其余与 0.19.0-rc.3 相同。
