**0.19.0 第三个预发布**：修复 iOS 上第三方输入法被禁的连坐。
配套服务端 v0.19.0-rc.3。协议 v6 不变。

## 修复（iOS 真机实测）

- 重命名仓库 / 向导新建仓库的**名字框**恢复第三方输入法：此前弹窗里常驻
  一个隐藏的 Token 密码框，「文本框 + 密码框」组合触发 WebKit 的登录表单
  启发式，名字框被当成用户名字段而连坐进 iOS 的凭据键盘限制。
  Token 补填框改为**被服务端拒绝时才创建**，不再常驻 DOM。
- 名字类输入框补 `autocomplete="off"`。

说明：密码框本身（E2EE 密码、Token）强制系统键盘是 iOS 安全策略
（secureTextEntry），无法解除；Token 通常粘贴输入，影响有限。

其余与 0.19.0-rc.2 相同。
