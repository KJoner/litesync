**公开化第一步：严格会话解锁、先核对后连接的连接链接、重整的设置页、本地完整替换远端。**
协议 v6 不变。连接链接 v2（先核对、断网续传）需要服务端 v0.20.0；旧服务端上插件自动退回原有配对流程，
并在界面上明说「无法在导入前核对仓库」。

> 草稿：服务端 v0.20.0 的 v2 端点联调与真机验收（Windows / iPhone / Android）完成之前不要发布。

## 默认改为严格会话解锁

- **新安装不再保存任何能自动解锁仓库的材料。** 仓库密码只在本次运行中使用；锁定、切换仓库或重启 Obsidian
  后需要重新输入。本设备保留的只有访问密文的设备凭据——状态卡把「设备已授权」与「仓库已解锁」分两行显示。
- 「信任此设备」改名为 **本设备自动解锁（可恢复密钥持久化）**，移到 设置 → 高级，默认关闭，开启前写明它保存了什么、
  防不住什么。解锁与启用加密的弹窗不再有勾选框。
- **从 0.19 升级的设备不会被打断**：本次运行照常自动解锁，设置页显示「旧设备信任待迁移」。迁移时先用仓库密码证明
  能解开**同一把**密钥（忘了密码也可以在这台仍能解锁的设备上为同一把密钥设新密码——绝不生成新密钥），确认待同步的
  修改已妥善保存，才清除旧材料。验证之前什么都不删；清理中途崩溃，重启后幂等完成。
- 如实说明：锁定 LiteSync 不会加密 Obsidian 已经保存的本地 Markdown 与附件。

## 连接链接 v2：先核对、后连接

- 设置首屏未连接时只有两个入口：**粘贴连接链接**、**打开网页注册或登录**；手工 Server URL / API Token 收进 高级 → 手动连接。
- 导入链接时**先只读**取配对包（打开、刷新落地页、链接预览都不会用掉它），在本机解密后展示**服务器、账号、仓库、
  信任方式与有效期**，你确认之后才兑换。
- 兑换前先把兑换编号落盘：断网或崩溃后用同一个编号重试，服务端返回同一份结果，不会多建一台设备，也不会卡在
  「链接已用掉却没拿到凭据」。超过 10 分钟作废并提示重新生成。
- 服务端返回的仓库与核对过的不一致 → 这份凭据一个字节都不用；配对包需要插件不认识的能力 → 拒绝导入并提示升级，
  绝不回落到默认仓库或旧的长期 Token 包。旧版 v1 配对包（含长期 Token）只做受限兼容导入，并要求确认风险。
- **添加新设备**为当前仓库申请一次性授权，包里写明仓库与账号；只有本机持有与当前 repoEpoch 一致的**已验证**检查点锚
  时才把锚交给新设备（界面显示「继承发行设备已验证的检查点」），否则如实写「首次信任」。新设备在接入完成、且仓库身份
  与 repoEpoch 都吻合时才采纳这个锚。

## 设置页重整

- 首屏状态卡：仓库、设备授权、仓库解锁、密钥保存方式、最近同步、冲突，外加**唯一**的主按钮（连接仓库 / 完成接入 /
  解锁仓库 / 立即同步）。
- 四节：连接与仓库、同步、加密与设备、高级（子页面：手动连接、密钥持久化、高级恢复、隐私增强、实验功能、调试）。
  沿用 Obsidian 原生设置项与主题变量。

## 高级恢复：用本地完整替换远端

- 新增于 设置 → 高级 与接入向导（两边都有内容时的第三张卡片）。远端在同步范围内变成本设备的样子：不同的以本地覆盖、
  远端多出来的删除（留 tombstone）、本地多出来的上传。
- 先生成完整差异预览（只读）→ 输入仓库名确认 → 把将被覆盖或删除的远端原始字节保存到插件目录作为恢复点（逐个读回校验）
  → 逐对象带版本前提写入，幂等键在预览时固定。远端或本地在预览之后有变化、或期间出现别的设备的写入 → 立即暂停，
  只能重新预览；断网可续跑，不重复写。完成后可生成**回滚**：远端恢复到替换之前（新 revision，不回退计数器），
  被替换掉的本地副本先备份。
- 与「用本地初始化空仓库」（只用于空远端）刻意分开命名；远端为空时本功能直接拒绝并引导过去。

## 修复

- 首次接入「合并」时，本地独有、但远端曾被删除过的同名文件会卡在 revision 冲突：协议 v6 下普通上传穿不透墓碑。
  现在先显式恢复原对象（身份与历史连续）再上传，与普通同步的处理一致。

## 升级说明

- 插件侧无数据迁移；data.json 新增 `keyPolicyVersion` 与 `trustMigration`，state.json 新增 `pendingPairingTrust`
  与 `replaceJob`，旧版本忽略它们。降级到 0.19.x：已完成严格模式的设备需要输入一次密码（0.19 会按旧默认重新保存信任材料）。
- 「本设备自动解锁」从 0.19 升级时保持原状直到你完成迁移；新安装默认关闭。
